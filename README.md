# NexaChat

Chat em tempo real usando Node.js + WebSocket.

## Rodar localmente
```bash
npm install
npm start
```
Abra:
http://localhost:3000

## Render
1. Crie um repositório no GitHub.
2. Envie todos estes arquivos para o repositório.
3. No Render, crie um Web Service conectado ao repositório.
4. Build Command: `npm install`
5. Start Command: `npm start`
6. O Render fornecerá uma URL HTTPS.

O WebSocket usa automaticamente `wss://` quando o site estiver em HTTPS.
